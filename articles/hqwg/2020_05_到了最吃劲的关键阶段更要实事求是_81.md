# 到了最吃劲的关键阶段更要实事求是

**作者**：李泾一

**栏目**：目 录

**期次**：2020年第5期

**来源**：<http://www.qstheory.cn/dukan/hqwg/2020-03/05/c_1125665570.htm>

---

习近平总书记指出，“各级党委和政府要实事求是做好防控工作，对偏颇和极端做法要及时纠正，不搞简单化一关了之、一停了之，尽可能减少疫情防控对群众生产生活的影响。”在疫情防控最吃劲的关键阶段，党中央突出强调实事求是，具有很强的针对性和十分重要的现实意义。各级领导干部必须坚持实事求是的思想路线和优良作风，做真正的“实事求是派”。

新冠肺炎疫情发生以来，以习近平同志为核心的党中央始终坚持实事求是的思想路线，发扬实事求是的工作作风，把人民群众生命安全和身体健康放在第一位，准确判断疫情形势，及时部署各项工作，果断采取有效举措，全面开展疫情防控工作。从统筹安排全国19个省份对口支援湖北抗疫，到武汉启用方舱医院确保应收尽收、应治尽治；从联防联控、群防群控，织密织牢疫情防控网，到全国各地复工复产的节奏越来越快……经过艰苦努力，疫情形势正在起变化，防控工作成效正在显现。实践证明，实事求是做好防控工作、打赢疫情防控人民战争的重要前提和根本保证。

任何事物运动发展都有规律可循。坚持实事求是，就要深入实际了解事物的本来面貌，要透过现象看本质，从零乱的现象中发现事物内部存在的必然联系，从客观事物存在和发展的规律出发，在实践中按照客观规律办事。疫情也不例外，其发生、发展和防控都有内在的规律性。掌握了疫情的特点和规律，就掌握了科学有序防控的主动权。当前，新冠肺炎疫情形势依然严峻，疫情对经济运行带来的冲击和影响也不小，我们既要毫不放松做好疫情防控重点工作，又要逐步恢复遭受疫情冲击的经济社会秩序。疫情防控已经到了最吃劲的关键阶段。越到关键时刻，越要以实事求是的态度对待疫情防控；越在吃劲的时候，越要以实事求是的方法处理疫情防控工作。

**坚持实事求是，必须做到疫情就是命令，防控就是责任，把人民群众生命安全和身体健康放在第一位。**疫情防控正处于胶着对垒状态，广大党员干部要坚持实事求是的态度和工作方法，全面贯彻“坚定信心、同舟共济、科学防治、精准施策”的要求，为党分忧、为国奉献，与人民同呼吸、共命运、心连心，全力以赴抓好疫情防控，全力以赴救治患者，争取尽早取得疫情防控斗争的全面胜利。各级党委政府遇到问题和困难的时候，在是非得失的权衡和取舍方面，要多从群众角度想问题办事情，急群众所急，解群众所忧，尽可能减少疫情防控对群众生产生活的影响，以实事求是的态度和作风访贫问苦，关心人民群众的疾苦和日常生活问题，切实拿出具体举措和有效方法帮助企事业单位复工复产，关心和解决生产、生活等人民群众切身利益问题，照顾好特殊群体和特困家庭，体现送温暖和人文关怀。

**坚持实事求是，必须认真贯彻习近平总书记提出的“突出重点、统筹兼顾，分类指导、分区施策”的要求。**具体问题具体分析，是实事求是活的灵魂。各级领导干部要全面准确摸清情况，弄清工作中的差距、短板、弱项，找出工作重点和努力方向，紧密结合本地区本部门本单位疫情实际，抓住当前疫情防治中最突出的矛盾和问题、最急需的工作和环节优先研究和部署，把精力和力量用到最关键、最要害处。要按照科学防治、精准施策原则，分区分级制定差异化防控策略。对于重点地区要进一步完善和加强防控，把各项工作抓细、抓实，坚决遏制疫情的蔓延。非疫情防控重点地区要以实行分区分级精准防控为抓手，统筹疫情防控与经济社会秩序恢复。各地的情况不一样，需要各级政府根据实际情况想办法，尽可能降低疫情对经济的影响。对偏颇和极端做法要及时纠正，不能搞一刀切地一关了之、一停了之，更不能搞疫情防控上的形式主义、官僚主义。

**坚持实事求是，必须把各项工作抓实、抓细、抓落地。**“一分部署，九分落实。”面对人员流动和聚集增加的新情况，面对依然严峻复杂的防控新形势，只满足于喊口号、下文件、做虚功，是解决不了问题的。广大党员干部必须挺身而出，坚守疫情防控前线，迎难而上，坚决贯彻党中央关于疫情防控各项决策部署，挽起裤腿、撸起袖子、扑下身子真抓实干，以更坚定的信心、更顽强的意志、更果断的措施，紧紧依靠人民群众，坚决把疫情扩散蔓延势头遏制住。要拿出具体办法措施，细化分解具体任务，压实具体责任，在细微处见党性，在细节中守初心、担使命，以抓铁有痕、踏石留印的韧劲，把疫情防控各项工作一抓到底、抓出成效。要一切着眼于全局、抓住防控重点、调动一切可用资源，从最有利于全局和整体利益的立场进行战略决策和统筹谋划，摈弃本位主义，跳出部门利益和地区利益的藩篱，做到全国一盘棋。

抗疫情、促发展，不仅是一场大战，而且是一场大考。各级领导干部只有坚持党的实事求是的思想路线和优良作风，才能在大战中践行初心使命，在大考中交出合格答卷，奋力夺取疫情防控和实现经济社会发展目标双胜利。
