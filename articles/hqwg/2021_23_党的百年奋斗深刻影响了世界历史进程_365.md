# 党的百年奋斗深刻影响了世界历史进程

《中共中央关于党的百年奋斗重大成就和历史经验的决议》指出，一百年来，党既为中国人民谋幸福、为中华民族谋复兴，也为人类谋进步、为世界谋大同，以自强不息的奋斗深刻改变了世界发展的趋势和格局。深入研究中国共产党百年奋斗对世界历史进程深刻影响的主要表现、必然逻辑和对人类文明作出更大贡献的路径，搞清楚中国共产党为什么会成为具有重大全球影响力的世界第一大执政党，具有重要的理论与现实意义。

**一**

党和人民事业是人类进步事业的重要组成部分。在百年的奋斗历程中，我们党创造了一个又一个辉煌成就，深刻影响了世界历史进程，产生了重大的全球影响力。

**1.党百年奋斗的辉煌成就深刻影响了世界历史进程**

中国共产党始终以世界眼光关注人类前途命运，从人类发展大潮流、世界变化大格局、中国发展大历史正确认识和处理同外部世界的关系，站在历史正确的一边，站在人类进步的一边，推动世界和平与发展事业。100年来，中国共产党把和平、发展、合作写在自己的旗帜上，无论是抗日战争时期积极推动形成反法西斯统一战线，还是新中国成立后奉行独立自主的和平外交政策，无论是倡导和平共处五项原则，还是准确把握和平与发展的时代主题，中国共产党通过维护世界和平发展自己，又通过自身的发展促进世界和平。中国共产党坚持公平正义，不懈推动人类自由解放的伟大事业。从第一个反帝反封建民主革命纲领，到上世纪六七十年代不遗余力地支持亚非拉国家民族解放运动，从在联合国等国际舞台上坚持为发展中国家仗义执言，到坚决抵制单边主义霸凌行径，中国共产党永远站在公平正义一边。中国共产党始终坚持合作共赢，不懈促进各国共同发展。从建设开放型经济到共建“一带一路”，从加大对发展中国家的援助到推动疫后世界经济复苏，中国共产党坚持互利共赢的开放战略，以中国的新发展为世界赢得新机遇。

《决议》指出：党领导人民成功走出中国式现代化道路，创造了人类文明新形态，拓展了发展中国家走向现代化的途径，给世界上那些既希望加快发展又希望保持自身独立性的国家和民族提供了全新选择。这一重要论断深刻揭示了中国共产党团结带领中国人民成功开辟中国特色社会主义道路、不断推进社会主义现代化建设的世界意义。中国共产党在百年砥砺奋进的过程中，探索出了一条涵盖经济、政治、文化、社会、生态等多层面、全方位、可持续的人类文明发展新道路，开创了独具特色的中国式现代化发展之路，在坚持中国特色社会主义道路的过程中创造出人类文明新形态。中国的成功实践表明，世界上根本不存在定于一尊的现代化模式，也不存在放之四海而皆准的现代化标准，每个国家都有探索自身发展道路的权利。

当今世界正面临百年未有之大变局，如何回答“世界怎么了、我们怎么办？”这个时代课题，是关乎人类前途命运的大问题。习近平总书记提出构建人类命运共同体的重大倡议，明确“中国外交的目标，就是要推动建设相互尊重、公平正义、合作共赢的新型国际关系，构建人类命运共同体”，深刻回答了“建设一个什么样的世界，怎样建设这个世界”的时代之问，解决了世界如何维护持久和平、实现共同发展的历史难题，为人类社会实现共同发展、持续繁荣、长治久安绘制了蓝图，成为引领时代潮流和人类文明进步方向的鲜明旗帜。只有秉持人类命运共同体理念，坚持多边主义、走团结合作之路，才能携手应对各种全球性问题，建设持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界。

**2.在全球经济政治活动中扮演着重要角色**

百年风雨兼程，党开创了伟大的中国特色社会主义事业，深刻影响着世界的发展格局。在历次国内外重大历史变局的关键节点，党始终坚持把马克思主义与中国实际相结合，站在人民群众的根本立场上，和世界各国人民一起致力于维护世界和平与促进共同发展的伟大事业，取得了举世瞩目的历史成就，带领中国人民所取得的巨大成就得到了国际社会的广泛认可。

在全球政党的相互往来中发挥了重要作用。改革开放以后，中国共产党同全球各政党的相互往来产生了历史性的转折，深化政党交流合作，发展成为具有中国特色的政党外交。中国共产党以其自身独特的亲和力和强大的感召力，同全球其他国家的政党进行了广泛的交流，开展中美、中欧、中俄、中非等对话，对世界的影响力越来越大。党的十八大以来，中国共产党逐步走近全球治理的世界舞台中央，积极与全球各政党建交，主动参与全球治理，成立了南南合作援助基金、国际发展知识中心等，推进“一带一路”建设，加强全球政党合作，同世界上五百多个政党和政治组织保持经常性联系，对世界发展趋势和格局影响越来越大。

中国共产党在全球范围内引领社会主义发展。20世纪末，苏东发生剧变，严冬笼罩着全球社会主义运动，社会主义发展面临着艰难险阻，对社会主义发展前途国际社会满怀各种质疑。中国共产党以实践中的辉煌成就证明了社会主义制度的优越性，证明了社会主义道路具有强大的生命力。在全球社会主义运动发展的关键时刻，中国共产党肩负起复兴社会主义的光荣使命，成为世界社会主义运动的中坚力量，在维护国家主权利益的同时壮大了世界社会主义力量，为国际影响力的提升进一步打下了坚实基础。

中国共产党在全球国际组织的交流中拥有越来越多的话语权。1972年中华人民共和国重返联合国，打开了对外工作新局面，开始全方位大踏步走向国际舞台。随着改革开放的深入推进，党领导中国人民积极活跃在全球交流的舞台中，与全球国际组织的合作也越来越紧密。党的十八大以来，在构建人类命运共同体理念指引下，中国高举和平、发展、合作、共赢的旗帜，推动建设新型国际关系，坚定维护国家主权安全发展利益，倡导共建“一带一路”，推动建设开放型世界经济，积极发展全球伙伴关系，积极参与全球治理体系变革和建设，中国共产党的全球影响力迈上了新台阶。

**3.构建人类命运共同体，创造了人类文明发展新形态**

构建人类命运共同体是引领时代潮流和人类前进方向的鲜明旗帜。构建人类命运共同体，是习近平新时代中国特色社会主义思想的重要组成部分，展现了习近平总书记胸怀天下、面向未来，大道之行、天下为公的宽阔胸襟。构建人类命运共同体的理论，是一个立意高远、思想深邃、内涵丰富的科学理论体系，具有鲜明的真理性、时代性、实践性，为解决人类重大问题，建设持久和平、普遍安全、共同繁荣、开放包容、清洁美丽的世界贡献了中国智慧、中国方案、中国力量。作为世界上最大的执政党，中国共产党始终关注着人类的前途命运，致力于积极营造和平发展的国际环境，为实现全球共赢发展贡献新契机，为人类文明发展开拓新格局，成为推动人类发展进步的重要力量。面对前所未有的崭新道路，在阻碍重重的征程上，中国共产党以中华民族和平、和睦、和谐的理念来诠释其广阔胸怀，始终注重传承中华民族的“和合”精神理念，即始终以和平、发展、合作、共赢为原则与世界各国携手共创合作共赢的发展新格局，携手推动人与自然和谐共生可持续发展的美好未来。

始终高举马克思主义伟大旗帜。马克思主义是中国共产党立党立国、兴党强国的根本指导思想。习近平总书记指出：马克思主义是我们立党立国的根本指导思想，是我们党的灵魂和旗帜。中国共产党为什么能，中国特色社会主义为什么好，归根到底是因为马克思主义行。习近平新时代中国特色社会主义思想是当代中国马克思主义、二十一世纪马克思主义，是中华文化和中国精神的时代精华，实现了马克思主义中国化新的飞跃。坚持以习近平新时代中国特色社会主义思想为指导对新时代党和国家事业发展、对推进中华民族伟大复兴历史进程具有决定性意义。

开创出将马克思主义与中华优秀传统文化有机结合的新局面。习近平总书记强调：以史为鉴、开创未来，必须继续推进马克思主义中国化。中华优秀传统文化是中华民族的根和魂，为中华民族克服困难、生生不息提供了强大的精神支撑。正是通过将中华文明与马克思主义结合起来，将马克思主义中国化，党才创造了伟大成就，创造了人类文明新形态，也深刻影响着世界。新的征程上，必须坚持把马克思主义基本原理同中国具体实际相结合、同中华优秀传统文化相结合，通过吸纳优秀传统文化，进一步扩充“中国特色”的丰富内涵，用马克思主义观察时代、把握时代、引领时代，继续发展当代中国马克思主义、二十一世纪马克思主义！

**二**

以社会主义制度优势为政治根基，以发展的巨大成就为物质保证，以自我革命精神为动力之源，中国共产党在全球范围内产生重大深刻的影响力。

**1.社会主义制度优势是政治根基**

中国共产党的百年奋斗深刻影响了世界历史进程，政治根基是社会主义的制度优势。我们党将开拓正确道路、发展科学理论、建设有效制度结合起来，把成功经验及时转化为制度成果，使国家制度既体现了科学社会主义原则，又具有中国特色、民族特色、时代特色。中国共产党领导，是中国特色社会主义制度的最大优势，是我国国家制度和国家治理体系的“核心密码”；始终代表最广大人民根本利益，是中国特色社会主义制度的本质属性，是我国国家制度和国家治理体系有效运行、充满活力的根本所在；集中力量办大事，是中国特色社会主义制度的显著特征，是我们成就事业的重要法宝。中国特色社会主义制度坚持把党的领导、人民当家做主、依法治国有机结合起来，符合我国国情，既坚持了社会主义的根本性质，又借鉴了古今中外制度建设的有益成果，集中体现了中国特色社会主义的特点和优势，是中国发展进步、深刻影响了世界历史进程的根本制度保障。西方资本主义国家总是以自己信仰的资本主义制度批判甚至诋毁中国特色社会主义制度。然而，西方忽略了一个不可否定的事实，中国共产党坚持的中国特色社会主义制度，使得中国获得了长足的发展，政治制度渐趋完善，经济水平大幅提高，人民能够安居乐业，社会安定而和谐。相反在鼓吹自由、平等、博爱的一些西方资本主义国家，却时常发生周期性经济危机、经常性恐怖袭击，社会动荡不安，政府行政效率低下。中国之治与西方之乱，形成鲜明对比。

**2.巨大的发展成就是物质保证**

新中国成立初期，由于长期处于战乱的局面，中国的生产条件十分落后，即使在这种艰难的处境中，党带领全国各族人民进行社会主义建设，为当今中国发展的腾飞作好了铺垫。改革开放以来，中国共产党高度重视经济发展，坚持以经济建设为中心，经济保持了较高增长速度，经济增长水平远远高于世界经济增长的平均水平。经过几十年的奋斗，中国的经济发生了惊人的巨变，由贫穷落后的国家一跃成为全球第二大经济体。党的十八大以来，我国国内生产总值突破百万亿元大关，人均国内生产总值超过一万美元，经济发展平衡性、协调性、可持续性明显增强，国家经济实力、科技实力、综合国力跃上新台阶。2020年，彻底解决困扰中华民族几千年的绝对贫困问题，全面建成小康社会，这一巨大成就必将载入人类文明史册。

**3.不断自我革命是动力之源**

中国共产党将马克思主义的自我革命精神作为自己前进的动力源泉，在取得辉煌成就的同时，保持清醒的头脑，在自我革命中不断前进。特别是在中国特色社会主义进入新时代，以习近平同志为核心的党中央以强烈的自我革命精神，践行党的初心使命，坚持反腐，弘扬正气，全面从严治党，确保了党的生机与活力，这是中国共产党能够不断前进、影响世界的内部动因。中国特色社会主义制度的鲜明品格就是善于自我完善、自我发展，这也是中国特色社会主义持续焕发活力的根本动因。我们党历经百年沧桑更加充满活力，其奥秘就在于敢于自我革命，始终坚持真理、修正错误。只有这样，才能够确保党不变质、不变色、不变味，确保党在新时代坚持和发展中国特色社会主义的历史进程中始终成为坚强领导核心，在为中国人民谋幸福的同时为世界发展进步作出更大的贡献。
