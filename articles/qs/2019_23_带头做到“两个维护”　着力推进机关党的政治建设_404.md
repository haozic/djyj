# 带头做到“两个维护”　着力推进机关党的政治建设

**作者**：佚名

**栏目**：评论

**期次**：2019年第23期

学习贯彻习近平总书记在中央和国家机关党的建设工作会议上的重要讲话精神，首要任务是强化政治意识，带头做到“两个维护”，着力推进机关党的政治建设。

**提高“两个维护”重要性的思想认识。**思想是行动的先导。政治上的成熟来自于理论上的成熟。“两个维护”的思想理论基础是马克思主义的唯物史观，其客观历史依据是我们对党的历史正反两方面经验科学总结得出的结论。马克思主义认为，人民群众是历史的创造者，是历史发展的动力，是社会历史前进的决定性力量。但同时也承认个人在历史上的重要作用。杰出的人物顺应历史发展的潮流，代表人民利益，满足人民愿望，就会对社会历史发展起加速的作用。恩格斯在《论权威》一文中列举过船长对汪洋大海上遇难船只得救所起关键作用的事例。列宁系统阐述过领袖、政党、阶级、群众之间的辩证关系，指出，群众是划分为阶级的，阶级是由政党来领导的，政党通常是由最有威信、最有影响、最有经验、被选出担任最重要职务而称为领袖的人们所组成的比较稳定的集团来主持的。毛泽东同志曾形象生动地说：“一个桃子剖开来有几个核心吗？不，只有一个核心。”邓小平同志强调：“任何一个领导集体都要有一个核心，没有核心的领导是靠不住的。”我们党在新民主主义革命28年的历史，以遵义会议为界标，可以分为前14年和后14年。前14年，我们党不成熟，没有形成坚强的领导集体和领导核心，革命不断遭受挫折。后14年，我们党形成了以毛泽东同志为核心的党中央，革命事业就从此不断从胜利走向胜利。

**“两个维护”是党在新时代取得的重大政治成果。**党的十八大以来，以习近平同志为核心的党中央以巨大的政治勇气和强烈的责任担当，提出了一系列新理念新思想新战略，出台了一系列重大方针政策，提出一系列重大举措，推进一系列重大工作，解决了许多长期想解决而没有解决的难题，办成了许多过去想办而没有办成的大事，推动党和国家事业取得历史性成就、发生历史性变革。尤其是我们党勇于面对遇到的重大风险考验和党内存在的突出问题，以顽强意志品质正风肃纪、反腐惩恶，消除了党和国家内部存在的严重隐患，党内政治生活气象更新，党内政治生态明显好转，党的创造力、凝聚力、战斗力明显增强，焕发出新的强大生机活力，为党和国家事业发展提供了坚强政治保证。回顾和思考其根本原因，就是因为有以习近平同志为核心的党中央的坚强领导，有习近平新时代中国特色社会主义思想的科学指引。“两个维护”就是在这样一个历史背景下产生的、提出的、形成的，成为全党的共识。它反映了全党全国人民的愿望，体现了全党全国人民的意志，是对党的十八大以来全面加强党对一切工作的领导、全面从严治党新鲜经验的深刻总结，是全党集体智慧的结晶。

**正确认识和把握“两个维护”的科学内涵和辩证关系。**“两个维护”成为党的十八大以来全党最重要的政治纪律和政治规矩，是新时代党的政治建设最根本的任务和最重要的内容。“两个维护”具有科学的内涵，是辩证统一的关系。维护核心，是维护习近平总书记党中央的核心、全党的核心地位；维护权威，是维护党中央权威和集中统一领导。维护习近平总书记核心地位，就是维护党中央权威和集中统一领导；维护党中央权威和集中统一领导，首先要维护习近平总书记核心地位。“两个维护”既不能层层套用，也不能随意延伸。全党只能向党中央看齐，决不能在地方部门单位打着维护党中央权威的旗号损害党的民主集中制，使“两个维护”变形走样。每一名党员、干部都必须牢记，不论做什么工作、在哪个岗位、在哪个部门、在哪个领域，也不论资格多老、级别多高，都是党员，都是党的干部，都是组织的人，第一位的身份是党员，第一位的职责是为党工作，重要的是要同党中央对标对表。

**做到“两个维护”的根本要求是对党忠诚。**“两个维护”不是抽象的，而是具体的。做到“两个维护”，也不是空喊口号，而是要体现和落实到实际行动中。能不能做到“两个维护”，根本的要求和前提是要对党忠诚。忠诚是共产党人政治品质的本质和核心，内含着信仰、信念和信心，内含着意志、道德和定力。具体地说，这种忠诚，就是对党的信仰的忠诚，对党的组织的忠诚，对党的理论和路线方针政策的忠诚。这种忠诚很纯洁，含金量很高，是唯一的、彻底的、无条件的、不掺任何杂质的、没有任何水分的。绝不能搞假忠诚，绝不能搞伪忠诚。对于一名党员和干部来说，对党的忠诚具体要体现在三个方面：一是要体现在坚决贯彻党中央决策部署的行动上；二是要体现在履职尽责、做好本职工作实效上；三是要体现在日常言行上。在做到“两个维护”上，必须是全面的、具体的、坚定不移的。

**中央和国家机关带头做到“两个维护”，是由其地位和性质所决定的。**中央和国家机关是党和国家设立的机构，代表着党和国家的形象，其宗旨和职责都是为人民服务。这就产生了政治，这就决定了它们的性质首先不是做具体工作的业务机关，而是政治机关。在这里没有脱离政治的单纯业务，也没有脱离业务的抽象政治，都必须旗帜鲜明讲政治，把政治建设摆在首位。进一步说，在党的组织体系中，中央和国家机关是处在组织结构的“第一方阵”，离党中央最近，服务党中央最直接，对机关党建乃至其他领域党建具有风向标作用。在国家治理体系中，中央和国家机关处在“最先一公里”和“第一棒”的位置。如果“第一方阵”出问题，危害会很大，属心腹之患而非皮癣之忧。如果“最先一公里”落空，“第一棒”掉链子，往后和向下的一切都会变形走样，甚至会相反。党史、新中国史上大量的事例都充分证明了这一点，我们要牢记历史给予的深刻启迪和警示。

**以政治建设为统领，建设让党中央放心、让人民满意的模范机关。**在深化党和国家机构改革中，党中央决定组建中共中央党史和文献研究院。这是党中央立足新时代中国特色社会主义事业和党的建设全局作出的一项重大战略决策。其目的是构建党的理论研究综合体系，打造党的历史和理论研究高端平台。其职责是为党续写和传承红色家谱、为马克思主义和马克思主义中国化创新成果“传经弘道”。因此，作为党中央直接领导的专门研究机构，我们要履行好职责，肩负起使命，完成好任务，就必须以习近平新时代中国特色社会主义思想为指导，认真学习贯彻习近平总书记在中央和国家机关党的建设工作会议上的重要讲话精神和党的十九届四中全会精神，增强“四个意识”，坚定“四个自信”，做到“两个维护”，立足新时代历史方位，加强党的领导，全面从严治党，把政治建院摆在首位，落实好意识形态责任制，发扬斗争精神，增强斗争本领，在政治历练和实践锻炼中建设高素质干部队伍。把习近平总书记的著作编辑好、出版好、阐释好，把党的历史、党的基本理论和党的领袖人物研究好、宣传好、维护好，讲好中国共产党的故事，讲好中国特色社会主义的故事，讲好党的领袖的故事。
