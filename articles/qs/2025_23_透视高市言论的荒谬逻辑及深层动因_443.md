# 透视高市言论的荒谬逻辑及深层动因

<div style="text-align:center">**透视高市言论的荒谬逻辑及深层动因**</div>

<div style="text-align:center">杨伯江</div>

台湾回归中国是二战胜利成果和战后国际秩序的重要组成部分，恪守一个中国原则是日本必须履行的严肃政治承诺。然而，高市早苗就任日本首相以来，在台湾问题上对华越线挑衅，在国会答辩中将“台湾有事”与日本“存亡危机事态”判定及行使集体自卫权挂钩，并且拒不撤回。高市此论是1945年日本战败以来，日本领导人首次在正式场合鼓吹所谓“台湾有事就是日本有事”并与行使集体自卫权相关联，首次在台湾问题上表达试图武装介入的野心，首次对中国发出武力威胁，用心极其险恶、性质极其恶劣、后果极其严重。如此挑衅性言论彻底暴露了她的错误史观以及反华立场，也折射出日本右翼势力正在沿着军国主义错误道路越走越远。

<div style="text-align:center">**一**</div>

台湾自古以来就是中国的神圣领土，而日本在台湾问题上对中国人民负有历史罪责。日本1894年发动甲午战争，次年强迫清政府签订不平等的《马关条约》，霸占台湾50年。日据时期，台湾人民灾难深重，数十万同胞被杀害，毫无政治权利、信仰自由和文化自由，宝岛的矿产资源、民生物资遭疯狂掠夺。日本侵略者在台湾犯下的罪行罄竹难书，是台湾历史最黑暗的一页。

台湾回归中国早在1945年中国人民抗日战争暨世界反法西斯战争胜利时就已彻底明确，并得到国际社会公认。1943年12月《开罗宣言》宣布，日本所窃取于中国之领土，例如东北四省、台湾、澎湖群岛等，归还中国。1945年7月《波茨坦公告》明确规定，“开罗宣言之条件必将实施”，并且要在清算日本军国主义侵略罪行基础之上，建立战后“正义之新秩序”。1945年8月9日，日本御前会议决定接受《波茨坦公告》，并于次日通过中立国瑞士和瑞典，向中美英苏四国政府发出乞降照会，表示接受公告所列条款。8月15日，日本天皇裕仁发布“终战诏书”，宣布接受《波茨坦公告》。9月2日，9位同盟国代表与日本代表签署《日本投降书》，昭告世界，日本政府、天皇及日本帝国大本营接受《波茨坦公告》，无条件投降。

1943年，《开罗宣言》宣布，三国之宗旨在使日本所窃取于中国之领土，例如东北四省、台湾、澎湖群岛等，归还中国。1945年，《波茨坦公告》重申“开罗宣言之条件必将实施”。同年9月，日本签署《日本投降书》，承诺“忠诚履行波茨坦公告各项规定之义务”。国际社会公认，这些具有国际法效力的文件为中国收复被日本军国主义掠夺和窃取的领土提供了重要的国际法依据，也是战后国际秩序的重要组成部分。图为《开罗宣言》英文版档案。 中新社供图

台湾问题纯属中国内政。1945年10月25日，中国政府宣告“恢复对台湾行使主权”，并在台北举行“中国战区台湾省受降仪式”。至此，中国从法律和事实上收复了台湾。1949年10月1日，中华人民共和国中央人民政府宣告成立，成为代表全中国的唯一合法政府。这是在中国这一国际法主体没有发生变化情况下的政权更替，中国的主权和固有领土疆域没有改变，中华人民共和国政府理所当然地完全享有和行使中国的主权，其中包括对台湾的主权。由于中国内战延续和外部势力干涉，海峡两岸陷入长期政治对立的特殊状态，但中国的主权和领土从未分割也决不允许分割，台湾是中国领土的一部分的地位从未改变也决不允许改变。1971年10月25日，第26届联合国大会通过第2758号决议，决定：“恢复中华人民共和国的一切权利，承认她的政府的代表为中国在联合国组织的唯一合法代表并立即把蒋介石的代表从它在联合国组织及其所属一切机构中所非法占据的席位上驱逐出去。”这一决议不仅从政治上、法律上和程序上彻底解决了包括台湾在内全中国在联合国的代表权问题，而且明确了中国在联合国的席位只有一个，不存在“两个中国”、“一中一台”的问题。一个中国原则成为国际社会的普遍共识，是遵守国际关系基本准则的应有之义。

一个中国原则是日本必须履行的条约义务。1972年9月，中日两国政府签订《中日联合声明》，宣布结束战争状态、建立外交关系。在台湾问题上，日本重申充分理解中方提出的“复交三原则”，即中华人民共和国政府是代表中国人民的唯一合法政府，台湾省是中华人民共和国领土不可分割的一部分，所谓“日蒋条约”非法无效，应予废除。日本国政府并重申“坚持遵循波茨坦公告第八条的立场”。1978年8月，《中日和平友好条约》以法律形式确认了上述各项原则和内容，明确指出，“联合声明所表明的各项原则应予严格遵守”。1998年11月，中日两国发表《中日关于建立致力于和平与发展的友好合作伙伴关系的联合宣言》，其中就台湾问题作出进一步规范。日方首次将“中国只有一个”写入中日政治文件，承诺“继续遵守日本在中日联合声明中表明的关于台湾问题的立场，重申中国只有一个。日本将继续只同台湾维持民间和地区性往来”。在此，日方清晰表明了“只有一个中国”，实际追溯确认了联合声明中“一个中国”的含义，同时对日台关系的定位也更清晰规范，即仅限于“民间和地区性往来”，从而排除了日本升级日台关系、适用国内法插手台海问题的法律空间。2007年12月，时任日本首相福田康夫访华，就台湾问题进一步阐明了日方立场：不搞“两个中国”或“一中一台”，不支持“台独”，不支持台湾“加入”联合国，不支持台湾当局搞“入联公投”。2008年5月，《中日关于全面推进战略互惠关系的联合声明》明确规定，日方“继续坚持在《日中联合声明》中就台湾问题表明的立场”。

此外，《联合国宪章》规定的“集体自卫权”是为维护国际社会集体安全、防止法西斯势力复活而创设的权利。日本在二战后被限制行使这一权利，这一限制源于其作为战败国的国际义务和国内宪法规定。《波茨坦公告》明确规定禁止日本重新武装，日本在其宪法中承诺“永远放弃发动战争、武力威胁或以武力作为解决国际争端的手段”。这些都是日本作为战败国义务的法律化。

由此可见，高市涉台极端言论暗示的所谓“台湾有事就是日本有事”的法理依据，是完全不存在的。她的挑衅性言论严重违背国际法和国际关系基本准则，严重破坏战后国际秩序，严重违背一个中国原则和中日四个政治文件精神，严重破坏中日关系政治基础，严重伤害中国人民感情。中国人民对此坚决反对，国际社会也应高度警惕。对心怀军国主义阴魂、挑战破坏国际秩序的行为隔岸观火，甚至纵容、挑唆，最终都会反噬自身。这是历史留下的深刻教训。

<div style="text-align:center">**二**</div>

值得关注的是，高市尽管刚刚上台毫无实际政绩，民调却显示她的支持率不降反升。根据共同社11月中旬民调结果，高市内阁支持率为69.9%，较10月上升5.5个百分点。民调不一定反映真正的民意，但是透过这一结果仍可以看到高市荒谬言论的背后存在一定的社会支持，反映出军国主义在日本国内仍有不小市场。

高市涉台极端言论的出台，与日本要竭力维护其战后非法既得利益的企图有关。二战结束后，随着美苏矛盾迅速发酵、东亚地区形势急剧变化，美国为排斥苏联、独占对战后日本的处理，对日政策迅速从削弱、去武装化转向扶植、重新武装。在美英的策划下，日本以非法、无效、中国不予承认的“旧金山和约”完成了与以欧美为主的二战作战对象国的片面媾和，同时与美国结成双边同盟。“旧金山和约”违反《联合国宪章》和国际法基本原则，单方面改变了《开罗宣言》、《波茨坦公告》、《日本投降书》等国际法文件在一系列重大问题上的规定，日本“同意”将它非法吞并的琉球交由美国“托管”。继而，美日私相授受，在1972年实施了琉球“施政权”的“移交”，且日方坚持中国的钓鱼岛（日方称尖阁列岛）是琉球的附属岛屿。为此，固化“旧金山和约”基础之上建立起来的伪“秩序”、防止中国统一激活琉球问题，成为日本外交的重要着眼点，也是高市之类谬论出台的深层动因。

高市涉台的极端言论，与高市内阁的右翼保守政权属性高度匹配。战后日本大量战犯未被清算，反而重返和活跃于战后日本政坛、军界和财界，这不仅使追究战争责任和揭露战争罪行成为不可能，也为日本右翼势力的死灰复燃种下了祸根。冷战后，日本经济经历了“失去的三十年”，实力严重下滑，导致日本政治右倾化现象愈演愈烈，带动日本社会呈现出整体右倾保守化趋势。与之形成鲜明对比的是，中国经济总量在2010年超过日本，至2024年已经达到日本的近5倍。竞争优势丧失、人口结构老化、增长势头衰减，开始从物质基础层面摧毁日本的战略自信。近年来，在以安倍晋三为首的右翼政客推动下，日本右翼势力迅速抬头，政治右倾化逐步发展为政坛普遍现象和重要特征，其主要表现是歪曲美化侵略历史、推动修宪强军、谋求“政治大国”化。高市涉险当选首相得益于党内外右翼保守势力的支持，更是与右翼政党维新会组成了“战后最保守的执政联盟”。以“外部威胁”为借口，为修改和平宪法、实现自卫队“正常化”、重走“军事大国”老路扫清障碍，台湾问题是他们撬动这个危险议程的支点之一。

2025年11月18日，外交部发言人在例行记者会上指出，中日关系出现目前局面，根源在于日本首相高市早苗公然发表涉台错误言论，粗暴干涉中国内政，严重违背一个中国原则和中日四个政治文件精神，破坏中日关系政治基础。日方必须立即收回错误言论，深刻反省，改弦更张，给中国人民一个明确的交代。图为当日例行记者会现场。 视觉中国供图

此外，高市谬论的背后，既有迎合美国维护地区霸权的需要，也有日本借此摆脱战败国束缚的图谋。一方面，美国需要日本具备服从性，要给曾经侵略扩张、祸害世界的日本带上紧箍。美国在占领时期主导制定的《日本国宪法》规定，日本“永远放弃以国权发动的战争、武力威胁或武力行使作为解决国际争端的手段”，“不保持陆海空军及其他战争力量，不承认国家的交战权”。另一方面，从冷战到今天，美国需要日本为其维护地区霸权充当桥头堡和马前卒。1950年朝鲜战争爆发后，日本在美国的要求下建立起“警察预备队”、“海上警备队”，直至发展到今天的自卫队。在当前大国博弈的背景下，美国实施战略调整，放松对日军事限制，日本右翼势力则借机强军扩武。从这个角度来说，高市涉台极端言论并非偶然，而是日本右翼势力在美国默许、纵容甚至是怂恿下，不断突破和平宪法束缚、谋求军事大国地位的必然结果。

<div style="text-align:center">**三**</div>

回望历史，殷鉴不远。近代日本军国主义对外疯狂侵略扩张，最终难逃覆灭下场。前车之鉴昭昭，高市若仍在军事扩张歧路上一意孤行，在对抗中国的道路上狂飙，只会将日本再次带往战争深渊，重蹈历史覆辙，为世界各国爱好和平的人民所坚决反对，被历史无情抛弃。

没有任何国家会容忍他国粗暴干涉本国内政，没有任何国家会容忍他国领导人对本国发出武力威胁。高市早苗公然违背日本所作的走和平道路的基本承诺，无视日本战后经济社会发展是基于反思二战历史教训而取得的事实，企图沿袭军国主义借势民粹的历史老路。这种蓄意挑衅的做法，暴露了其危险的战略企图，对台海和平与地区安全稳定构成严重威胁。在大是大非面前，中国人绝不含糊。台湾问题是中国核心利益中的核心，是不可触碰的红线和底线。以何种方式解决台湾问题、实现国家统一，是中国人民自己的事，不容任何外部势力干涉。80年前，英勇的中国人民打败了日本侵略者。80年后的今天，中国人民捍卫国家主权和领土完整的决心坚如磐石，意志坚不可摧，能力今非昔比。借炒作台湾问题实现强军扩武的政治企图、无视时代潮流与中国统一决心的军事冒险主义，必将遭到中国人民的迎头痛击。

由于殖民和侵略历史，日本的军事安全动向一直备受亚洲邻国和国际社会关注。俄罗斯联邦安全会议秘书绍伊古表示，高市早苗奉行历史修正主义政策，日方发表大量反俄言论，与其声称的对俄关系正常化意愿互相矛盾；韩国政府对高市声称独岛（日方称竹岛）是日本“固有领土”表示严正抗议，并暂停了原定于11月举行的韩日联合演习。针对高市关于提高日本防卫费支出、提前修订国家安全战略等言论，朝鲜媒体发文批评日本暴露了“战争国家的丑恶嘴脸”……高市早苗的挑衅言行引发周边多国同声抗议批评，为冷战结束以来所罕见。这表明，日本已经成为破坏亚太和平的重大风险源。

高市政权极端错误、极为危险的举动同样招致日本国内有识之士广泛批评。日本最大在野党立宪民主党党首、日本前首相野田佳彦11月16日在党内会议上批评高市早苗“言论越界，导致日中关系陷入非常严峻的局面”。日本“继承和发展村山谈话会”理事长藤田高景一针见血地指出，高市早苗的言论违背国际法，严重伤害日中两国关系，“日本不能允许任何政治力量将国家再次推向战争深渊”。日本《东京新闻》社论批评其言论“鲁莽且轻率”，强调作为首相发表这样的言论“不能被接受”。日本网民直言高市早苗“缺乏外交常识”，要求其撤回错误表态；更有民众自发组织集会，抗议其不负责任的挑衅行为。从最大在野党党首的严厉批评，到知名社会活动家的痛心疾首，再到媒体的忧心忡忡和民众的不满抗议，凡此种种，无不说明日本社会仍存理性声音与守护和平的力量。

今年是中国人民抗日战争暨世界反法西斯战争胜利80周年，也是台湾光复80周年。日本军国主义历史上曾多次以所谓“存亡危机”为借口发动对外侵略，包括以“行使自卫权”为由悍然制造九一八事变，挑起侵华战争，给包括中国在内的亚洲乃至世界人民带来深重灾难。在日本战败投降80年后的今天，日方不是反省罪恶历史、吸取惨痛教训，其首相高市早苗反而抛出涉台谬论且态度恶劣，这不仅是战略鲁莽，更是蓄意挑衅。人们不禁要问，日本是否要重蹈军国主义覆辙？是否要再次同中国人民和亚洲人民为敌？是否企图颠覆战后国际秩序？历史可能相似，但不会重复。不会重复的是，中国人民和亚洲各国人民将不再任人宰割，而是有实力有能力维护国家主权利益。相似的是，靠穷兵黩武重振帝国美梦的日本右翼势力、军国主义好战分子必将被永远钉在历史的耻辱柱上。
